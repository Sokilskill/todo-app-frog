# Todo App Frog 🐸

![Home page](/public/screenshot1.png)

Додаток для управління завданнями, розроблений на **React**, **Redux Toolkit** та **Tailwind CSS**. Основний фокус зроблений на чіткій структурі проєктів та зберіганні даних.

## 🚀 Функціонал

- **Управління проєктами:** Створення та редагування проєктів.
- **Керування завданнями:** Створення, редагування та видалення завдань.
- **Прив'язка до проєкту:** Кожне завдання можна закріпити за певним проєктом.
- **Параметри завдань:** Встановлення пріоритету (низький, середній, високий) та вибір кольору.
- **Фільтрація:** Сортування завдань за фільтрами.
- **Теми:** Підтримка темної та світлої тем оформлення.
- **Збереження даних:** Постійне зберігання стану в `localStorage` за допомогою `redux-persist`.

## 🛠 Стек технологій

- **Frontend:** React.js
- **Управління станом:** Redux Toolkit (RTK)
- **Збереження:** Redux Persist (локальне сховище)
- **Стилізація:** Tailwind CSS

## 📦 Запуск проєкту

1. **Клонувати репозиторій:**

   ```bash
   git clone https://github.com/Sokilskill/todo-app-frog.git

   cd todo-app-frog
   ```

2. **Встановити залежності**
   ```bash
    npm install
   ```
3. **Запустити сервер розробки**
   ```bash
   npm run dev
   ```
